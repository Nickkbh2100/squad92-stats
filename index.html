Kampe pr. spiller
Regler for hvilke kampe der tæller
  • Kun Duo og Squad (TPP og FPP), officielle kampe og ranked. Custom, events og træning tæller ikke.
  • Hele holdet skal bestå af Squad92-medlemmer, og mindst 2 af jer skal være med. Er der en tilfældig spiller med via fill, tæller kampen ikke.
  • Hver spillers gennemsnit regnes ud fra hans egne seneste godkendte kampe.
  • Data hentes automatisk fra PUBG's officielle API ca. én gang i timen.
